# Web_App

To-do web app (formerly `todo-app`). Live at https://todo.voraphon.com

- App: `public/index.html` (single file, Supabase backend)
- Database changes: `supabase/migrations/`
- Plan and open items: `NEXT-STEPS.md`
- Deploy: upload only the `public/` folder to Netlify

## Other apps in this repo

- `food-order/`: group food ordering (open access, Supabase realtime, schema `food_order`). See `food-order/README.md`
