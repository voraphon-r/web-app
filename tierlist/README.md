# Tier List

เว็บทำ tier list (จัดอันดับด้วยรูป) แบบหน้าเดียว ทำงานในเบราว์เซอร์ล้วน ๆ ไม่มี backend
รูปที่อัปโหลดอยู่ในเครื่องผู้ใช้เท่านั้น ไม่ถูกส่งขึ้นเซิร์ฟเวอร์ใด ๆ

- หน้าเว็บ: `public/index.html` (ไฟล์เดียว HTML + CSS + JS, ไม่มี dependency)
- เปิดไฟล์ตรง ๆ จากเครื่องก็ใช้ได้ ไม่ต้องรันเซิร์ฟเวอร์
- มี Content-Security-Policy กันไม่ให้หน้าเว็บส่ง network request ออกไปไหน

## ใช้งาน

- **อัปโหลดรูป**: ปุ่ม "อัปโหลดรูป" (เลือกหลายไฟล์ได้), ลากไฟล์มาวาง, หรือ Ctrl+V รูปย่อเหลือด้านยาว 300px ตอนนำเข้า
- **ลากจัดอันดับ**: เมาส์ลากได้เลย / มือถือ กดค้างครู่หนึ่งแล้วลาก (ปัดเร็ว ๆ = เลื่อนหน้า)
- **เมนูรูป**: คลิกขวา หรือกดค้างแล้วปล่อย → ย้ายกลับคลัง, ใส่ข้อความใต้รูป, ลบรูป
- **แถว**: คลิกป้ายเพื่อแก้ชื่อ, ปุ่ม ⚙ เปลี่ยนสี/แทรก/เลื่อน/ล้าง/ลบแถว, ลากที่ ⠿ เพื่อย้ายแถว
- **ครอป**: จัตุรัส, แนวนอน 16:9, แนวตั้ง 3:4, วงกลม, ไม่ครอป
- **ดาวน์โหลด PNG**: วาดด้วย canvas ความละเอียด 2x ไม่รวมคลังรูป ชื่อไฟล์ = ชื่อ tier list + วันที่
- **โหมดนำเสนอ**: เต็มจอ เริ่มจากแถวว่าง กด → / คลิก เพื่อเผยรูปทีละรูป, ← ย้อน, Esc ออก
- **บันทึกอัตโนมัติ** ใน IndexedDB (รีเฟรชแล้วงานยังอยู่), **บันทึก/เปิด JSON** ไว้ส่งให้เพื่อน
- **Undo/Redo**: Ctrl+Z / Ctrl+Y (50 ขั้น)
- ธีมสว่าง/มืด ตามเครื่อง หรือกดสลับเอง

## Deploy (Netlify)

Netlify project แบบ Git-linked กับ repo นี้: Base directory `tierlist`, Publish directory `tierlist/public`, ไม่มี build command
